# 🤖 Финансовый Telegram-бот

Бот для учёта личных финансов: добавление операций простым текстом,
баланс, отчёты с диаграммами, лимиты по категориям и регулярные платежи.

## Возможности

- ➕ Добавление операций обычным текстом: `-500 кофе` — трата, `+50000 зарплата` — доход
- 💰 Автоматический подсчёт баланса
- 📊 Круговая диаграмма расходов за период (день / неделя / месяц / год)
- 🎯 Отчёт за произвольный период с выбором дат через интерактивный календарь
- ⚠️ Лимиты по категориям с предупреждением о превышении
- 🔁 Регулярные платежи: автосписание и напоминания (подписки, аренда)
- 📁 Экспорт истории операций в CSV

## Технологии

- Python 3.11+
- aiogram 3.x — асинхронный фреймворк для Telegram Bot API
- SQLite + aiosqlite — асинхронное хранение данных
- matplotlib — построение диаграмм
- python-dotenv — хранение токена в переменных окружения

## Установка и запуск

1. **Клонируй репозиторий:**

   ```bash
   git clone https://github.com/ТВОЙ_НИК/finance-bot.git
   cd finance-bot

2. **Установи зависимости:**

   ```bash
   pip install -r requirements.txt

3. **Создай бота:**

   ```bash
   Открой @BotFather в Telegram
   Отправь команду /newbot, задай имя и username
   Скопируй выданный токен

4. **Создай файл .env в корне проекта:**

   ```bash
   TELEGRAM_BOT_TOKEN=токен_от_botfather

5. **Запусти бота:**

   ```bash
   python main.py
   
6. **Открой бота в Telegram по ссылке из BotFather и нажми /start**
