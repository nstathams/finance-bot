# 🤖 Финансовый Telegram-бот

Бот для учёта личных финансов: добавление операций простым текстом,
баланс, отчёты с диаграммами, лимиты по категориям и регулярные платежи.

## Возможности

- ➕ Добавление операций обычным текстом: `-500 кофе` — трата, `+50000 зарплата` — доход
- 💰 Автоматический подсчёт баланса
- 📊 Круговая диаграмма расходов за период (день / неделя / месяц / год)
- 🎯 Отчёт за произвольный период с выбором дат через интерактивный календарь
- ⚠️ Лимиты по категориям с предупреждением при 80% и превышении лимита
- 🔁 Регулярные платежи: автосписание и напоминания (подписки, аренда)
- 📁 Экспорт истории операций в CSV

## Технологии

- Python 3.11+
- aiogram 3.x — асинхронный фреймворк для Telegram Bot API
- SQLite + aiosqlite — асинхронное хранение данных
- matplotlib — построение диаграмм
- python-dotenv — хранение токена в переменных окружения

## Установка и запуск

1. **Клонируй репозиторий:**

   ```bash
   git clone https://github.com/username/finance-bot.git
   cd finance-bot
   ```

2. **Создай и активируй виртуальное окружение:**

   ```bash
   python -m venv venv
   venv\Scripts\activate      # Windows
   source venv/bin/activate   # Linux/macOS
   ```

3. **Установи зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Создай бота:**

   Открой [@BotFather](https://t.me/BotFather) в Telegram, отправь команду `/newbot`,
   задай имя и username, скопируй выданный токен.

5. **Создай файл `.env` в корне проекта:**

   ```bash
   TELEGRAM_BOT_TOKEN=токен_от_botfather
   ```

6. **Запусти бота:**

   ```bash
   python main.py
   ```

7. **Открой бота в Telegram по ссылке из BotFather и нажми /start.**

## Как пользоваться

Бот понимает операции, написанные обычным текстом — знак определяет тип:

| Пример            | Что делает                      |
|-------------------|---------------------------------|
| `-500 кофе`       | Трата 500 ₽ на категорию «кофе» |
| `+50000 зарплата` | Пополнение на 50 000 ₽          |
| `-1200 такси`     | Трата 1 200 ₽                   |

Дробные суммы тоже работают: `-150,50 продукты`.

Через меню бота доступны разделы:

| Раздел                 | Что внутри                                                                    |
|------------------------|-------------------------------------------------------------------------------|
| 💰 Баланс              | Текущий баланс, доходы и расходы за день / неделю / месяц / год               |
| ➕ Добавить операцию   | Пошаговый ввод траты или пополнения                                           |
| 📜 История трат        | Последние операции                                                            |
| 📊 Визуализация        | Круговая диаграмма расходов за выбранный период                               |
| 🎯 Лимиты              | Установка, изменение, сброс счётчика и удаление лимитов по категориям         |
| 🔁 Регулярные платежи  | Подписки и зарплата: автосписание или напоминание с выбранной периодичностью  |
| 🧾 Отчёт и аналитика   | Сводка за произвольный период с выбором дат                                   |
| 📁 Экспорт CSV         | Выгрузка истории операций файлом                                              |

## Структура проекта

```
finance-bot/
├── main.py                   # точка входа: запуск polling и планировщика
├── scheduler.py              # фоновый планировщик регулярных платежей
├── database/
│   └── db_manager.py         # все запросы к SQLite (aiosqlite)
├── handlers/
│   ├── keyboards.py          # клавиатуры главного меню
│   ├── transactions.py       # быстрый ввод и пошаговое добавление операций
│   ├── limits.py             # меню лимитов
│   ├── recurring.py          # регулярные платежи
│   └── reports.py            # отчёты и визуализация
├── parsers/
│   └── transaction_parser.py # разбор текста операции
├── utils/
│   ├── errors.py             # свои исключения (InvalidFormatError, DatabaseError)
│   └── chart_generator.py    # построение диаграмм (matplotlib)
├── tests/
│   ├── test_transaction_parser.py
│   └── test_db_manager.py
├── requirements.txt
└── .env                      # токен (не попадает в git, см. .gitignore)
```
